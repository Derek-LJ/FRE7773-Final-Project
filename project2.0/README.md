# Project 2.0

## Project Structure

This project follows a structured approach for financial data analysis and modeling.

## Directory Overview

- `data_raw/`: Raw data files
- `data_processed/`: Processed and cleaned data
- `eda/`: Exploratory data analysis scripts and outputs
- `src/`: Source code organized by functionality
  - `data/`: Data preprocessing and train/test splitting
  - `features/`: Feature engineering modules
  - `regression/`: Regression models
  - `classification/`: Classification models
  - `evaluation/`: Model evaluation scripts
  - `interpretation/`: Model interpretation using SHAP
- `notebooks/`: Jupyter notebooks for analysis
- `report/`: Project reports
- `presentation/`: Presentation materials
